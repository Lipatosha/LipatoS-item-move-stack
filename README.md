# LipatoS - Перемещение и стопки предметов

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который расширяет работу с инвентарём, переносом предметов и стопками.

## Версия

**34.2.2**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.0–6.0.6** (целевая версия; проверка непосредственно в Foundry ещё требуется)

## Возможности

- **динамический вес**: у ГМа на карточке предмета появляется кнопка для включения и настройки веса пустого предмета и веса одного заряда; вес автоматически пересчитывается по оставшимся зарядам (D&D5e `system.uses.spent`), в том числе при использовании, пополнении, переносе и изменении максимума зарядов — масса одного заряда при этом не меняется;
- переносит предметы между персонажами и группами с выбором количества;
- автоматически объединяет одинаковые стопки у получателя;
- позволяет объединять одинаковые стопки внутри одного инвентаря перетаскиванием;
- добавляет пункт **«Передать предмет»** в контекстное меню;
- позволяет группе разделять стопки предметов;
- добавляет группе шкалу текущего и максимального переносимого веса; максимальный вес изменяет только ГМ;
- **для игроков и ГМа** открывает предметы левой кнопкой в режиме просмотра;
- делает карточки предметов для игроков только для чтения;
- запрещает игрокам вручную изменять количество предметов и скрывает кнопки изменения количества;
- добавляет **«Использовать»** первым пунктом ПКМ **у игроков и ГМа**: он запускает исходное стандартное действие ЛКМ системы D&D5e, без дублирующих команд;
- удаляет пункт **Give To Character** из ПКМ и у ГМа, и у игроков, оставляя наш пункт **«Передать предмет»**;
- удаляет у игроков пункты редактирования и копирования;
- ГМ сохраняет право редактировать предметы, но обычная ЛКМ тоже открывает карточку в режиме просмотра.

Пункт **«Использовать»** повторяет штатное действие D&D5e по нажатию на название предмета — без отдельной реализации расхода или броска в этом модуле. Если раньше ЛКМ отправляла предмет в чат, пункт ПКМ делает то же самое. Для автоматического расхода еды и напитков по-прежнему используется модуль **LipatoS — Мгновенное употребление** и настроенная активность.

## Динамический вес и цена зарядов (с версии 34.2.2)

1. От имени **ГМа** откройте предмет со стандартными зарядами D&D5e, во вкладке **«Подробности»** нажмите **«Динамический вес: настроить»**.
2. Задайте максимальное количество зарядов самого предмета (например, `100`).
3. Включите динамический вес и укажите два значения: **вес пустого предмета** (например, `5` фунтов) и **вес одного заряда** (например, `0,45` или `0.45` фунта). Нажмите «Сохранить».
4. Вес изменяется автоматически: `вес = вес пустого предмета + вес одного заряда × оставшиеся заряды`.

5. По желанию включите **«Пересчитывать цену от зарядов»**, укажите **цену одного заряда** (например, `2`) и валюту: **медь (мм)**, **серебро (см)** или **золото (зм)**. Если включено, стоимость предмета равна цене одной порции, умноженной на число оставшихся зарядов. Например, при 55 порциях по 2 см общая цена — 110 см. Цена пустой тары в расчёт не включена. При отключённой опции модуль цену не изменяет.

**Исправление сохранения:** в Foundry v14 значения формы берутся через `button.form.elements`; окно больше не использует вложенную HTML-форму. Вводятся и `0.5`, и `0,5`, целые значения тоже работают.

Пример для бочки пива с максимумом 100 порций: 100 зарядов → **50 фунтов**, 55 зарядов → **29,75 фунта**, 0 зарядов → **5 фунтов**. Если максимум станет 200, каждая порция **всё равно будет весить 0,45 фунта**, без необходимости перенастройки.

Окно настройки уменьшено до 700 пикселей. Можно вводить числа с точкой или запятой: `0.5`, `0,5`, а также целые (`0`, `1`, `5`).

**Обновление с 34.1.0:** прежние параметры «вес полного предмета» и «вес пустого предмета» автоматически переводятся в новую настройку при загрузке мира ГМом. Формула миграции: `вес одного заряда = (прежний полный вес − прежний пустой вес) / прежний максимум зарядов`. Старые данные остаются читаемыми и до миграции, в том числе для непривязанных токенов.

Настройка хранится в самом предмете и переносится вместе с ним. Масса изменяется в стандартном поле `system.weight.value`, поэтому штатная грузоподъёмность и таблицы инвентаря учитывают её. Веса относятся к **одной единице предмета**, а не ко всей стопке. Единицы измерения соответствуют выбранным единицам веса карточки; после смены единиц измерения нужно перенастроить массы. При отключении динамического веса последний вычисленный вес сохраняется. Предметы без включённой опции не изменяются.

## Совместимость со старой версией

При переходе со старого модуля `item-move-stack` сохранённое значение максимального веса группы автоматически переносится в новый флаг `lipatos-item-move-stack`.
