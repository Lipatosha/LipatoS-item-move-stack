# История изменений

## 34.0.1

- Добавлена совместимость с D&D5e 6.0.5.
- Обновлены манифест и установочный архив модуля.
- Рабочая логика модуля сохранена без изменений.

## 34.0.0

- Текущая рабочая версия перенесена в линейку модулей LipatoS.
- Внутренний ID изменён с `item-move-stack` на `lipatos-item-move-stack`.
- Автор и название модуля приведены к бренду **LipatoS**.
- Сохранены перенос предметов, объединение и разделение стопок, выбор количества при передаче и работа с группами.
- Сохранена шкала грузоподъёмности группы.
- Сохранены ограничения игроков на ручное изменение количества и редактирование карточек предметов.
- Собственная функция «Использовать» по-прежнему отсутствует.
- Добавлен автоматический перенос старого флага максимального веса группы из `item-move-stack` в `lipatos-item-move-stack`.
