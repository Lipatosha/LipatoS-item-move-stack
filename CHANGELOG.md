# История изменений

## 34.0.4

- Исправлена отсутствующая кнопка **«Использовать»** в ПКМ у ГМа.
- У ГМа и игроков команда «Использовать» теперь появляется первой и вызывает штатное действие D&D5e.
- Вторая одинаковая команда удаляется, даже если её создаёт система или другое дополнение.
- ЛКМ открывает просмотр предмета для обеих ролей; прочие ограничения и перенос стопок сохранены.

## 34.0.3

- У ГМа ЛКМ теперь открывает карточку предмета в режиме просмотра, как у игрока.
- Для ГМа сохраняется штатный пункт «Использовать» в ПКМ: второй пункт не создаётся.
- У игроков ПКМ → «Использовать» по-прежнему запускает штатное действие D&D5e.
- Запрет «Give To Character» для всех ролей и остальные функции сохранены.

## 34.0.2

- Пункт **«Использовать»** добавлен первым в контекстное меню предмета для игроков и ГМа.
- Пункт вызывает прежнее штатное действие ЛКМ D&D5e, обходя перехват ЛКМ для просмотра карточки.
- **Give To Character** удаляется из контекстного меню для всех ролей, в том числе при позднем добавлении сторонним модулем.
- Пункт **«Передать предмет»**, ограничения инвентаря и просмотр по ЛКМ сохранены.
- Добавлены проверки поведения для игроков и ГМа.

## 34.0.1

- Добавлена совместимость с D&D5e 6.0.5.
- Обновлены манифест и установочный архив модуля.
- Рабочая логика модуля сохранена без изменений.

## 34.0.0

- Текущая рабочая версия перенесена в линейку модулей LipatoS.
- Внутренний ID изменён с `item-move-stack` на `lipatos-item-move-stack`.
- Автор и название модуля приведены к бренду **LipatoS**.
- Сохранены перенос предметов, объединение и разделение стопок, выбор количества при передаче и работа с группами.
- Сохранена шкала грузоподъёмности группы.
- Сохранены ограничения игроков на ручное изменение количества и редактирование карточек предметов.
- Собственная функция «Использовать» по-прежнему отсутствует.
- Добавлен автоматический перенос старого флага максимального веса группы из `item-move-stack` в `lipatos-item-move-stack`.
