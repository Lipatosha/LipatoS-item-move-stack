# История изменений

## 34.2.3

- ПКМ → «Использовать» доступно для расходников, добычи, инструментов и оружия, но не для снаряжения и контейнеров.
- Команда использует LipatoS-Instant-Consumables v1.3.0 для отправки карточки в чат и мгновенного списания заряда либо единицы количества.
- Для предметов без активностей теперь работает прямое использование через API модуля; атаки оружием остаются обычными.
- Просмотр ЛКМ, передача предметов, динамический вес и стоимость зарядов не меняются.


## 34.2.2

- Исправлено сохранение веса в Foundry VTT 14: значения читаются через штатный `button.form.elements` без вложенной формы.
- Добавлена необязательная автоматическая стоимость зарядов: цена одного заряда, валюта — медь, серебро или золото.
- Общая цена предмета изменяется при расходе, пополнении и изменении числа зарядов только после включения опции.
- Сохранён компактный диалог и поддержка десятичной запятой, точки и целых чисел.
- Добавлены тесты, имитирующие настоящий callback DialogV2 и проверяющие расчёт цены.


## 34.2.1

- Поля динамического веса принимают десятичную точку и запятую, а также целые значения.
- Окно настройки уменьшено до 700 пикселей.
- Ввод весов переведён на текстовые поля с десятичной клавиатурой, чтобы не терять значения с запятой.
- Добавлены тесты формы для `0.5`, `0,5`, целых и некорректных значений.
- Остальная функциональность не изменена.


## 34.2.0

- Настройка динамического веса изменена: вместо веса полной ёмкости ГМ указывает **вес одного заряда** и **вес пустого предмета**.
- Формула: пустой вес + оставшиеся заряды × вес одного заряда. Изменение максимума зарядов не влияет на массу одной порции.
- Добавлена автоматическая миграция старых настроек v34.1.0 с сохранением веса одной порции и обратной совместимостью старых предметов.
- Сохранены пересчёт при использовании и пополнении, все ограничения инвентаря и меню ЛКМ/ПКМ.


## 34.1.0

- Добавлен **динамический вес предмета**, зависящий от текущего количества оставшихся зарядов.
- В карточке предмета ГМ может включить динамический вес и задать вес полной и пустой ёмкости.
- Пересчёт использует поле D&D5e 6.x `system.uses.spent` и учитывает изменения максимального числа зарядов.
- Пересчёт выполняется при использовании/пополнении предмета, а также после его копирования или передачи.
- Настройки сохраняются в флаге самого предмета; остальные предметы и режимы ЛКМ/ПКМ остаются без изменений.


## 34.0.4

- Исправлена отсутствующая кнопка **«Использовать»** в ПКМ у ГМа.
- У ГМа и игроков команда «Использовать» теперь появляется первой и вызывает штатное действие D&D5e.
- Вторая одинаковая команда удаляется, даже если её создаёт система или другое дополнение.
- ЛКМ открывает просмотр предмета для обеих ролей; прочие ограничения и перенос стопок сохранены.

## 34.0.3

- У ГМа ЛКМ теперь открывает карточку предмета в режиме просмотра, как у игрока.
- Для ГМа сохраняется штатный пункт «Использовать» в ПКМ: второй пункт не создаётся.
- У игроков ПКМ → «Использовать» по-прежнему запускает штатное действие D&D5e.
- Запрет «Give To Character» для всех ролей и остальные функции сохранены.

## 34.0.2

- Пункт **«Использовать»** добавлен первым в контекстное меню предмета для игроков и ГМа.
- Пункт вызывает прежнее штатное действие ЛКМ D&D5e, обходя перехват ЛКМ для просмотра карточки.
- **Give To Character** удаляется из контекстного меню для всех ролей, в том числе при позднем добавлении сторонним модулем.
- Пункт **«Передать предмет»**, ограничения инвентаря и просмотр по ЛКМ сохранены.
- Добавлены проверки поведения для игроков и ГМа.

## 34.0.1

- Добавлена совместимость с D&D5e 6.0.5.
- Обновлены манифест и установочный архив модуля.
- Рабочая логика модуля сохранена без изменений.

## 34.0.0

- Текущая рабочая версия перенесена в линейку модулей LipatoS.
- Внутренний ID изменён с `item-move-stack` на `lipatos-item-move-stack`.
- Автор и название модуля приведены к бренду **LipatoS**.
- Сохранены перенос предметов, объединение и разделение стопок, выбор количества при передаче и работа с группами.
- Сохранена шкала грузоподъёмности группы.
- Сохранены ограничения игроков на ручное изменение количества и редактирование карточек предметов.
- Собственная функция «Использовать» по-прежнему отсутствует.
- Добавлен автоматический перенос старого флага максимального веса группы из `item-move-stack` в `lipatos-item-move-stack`.
